# 校园快递驿站管理系统 接口文档

统一返回格式：

```json
{ "code": 200, "msg": "操作成功", "data": {} }
```

- `code = 200` 成功；`401` 未登录；`403` 无权限；`400` 参数错误；`500` 业务/系统异常。
- 分页返回 `data` 结构：`{ "total": 总数, "records": [...] }`。
- 在线可视化文档：启动后访问 `http://localhost:8081/doc.html`（Knife4j，端口以 `application.yml` 的 `server.port` 为准）。

| POST | /api/login | 登录，body: `{username, password}` |
| POST | /api/logout | 退出登录 |

## 2. 快件管理

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| POST | /api/package/in | 入库登记，body 见下 | 登录 |
| GET | /api/package/page | 分页查询 | 登录 |
| GET | /api/package/detail/{id} | 快件详情 | 登录 |
| GET | /api/package/logs/{id} | 快件操作日志 | 登录 |
| POST | /api/package/notice/{id} | 发送取件通知 | 登录 |
| POST | /api/package/notice/batch | 批量通知，body: `[id1, id2]` | 登录 |
| POST | /api/package/pickup | 取件办理，body 见下 | 登录 |
| DELETE | /api/package/{id} | 删除快件 | 超级管理员 |

**入库 body**：`{trackingNo, companyId, receiverName, receiverPhone, shelfNo?, remark?}`

**取件 body**：`{type, pickupCode?, phone?, trackingNo?}`
- `type = PICKUP_CODE` 需 `pickupCode`；`type = PHONE_TAIL` 需 `trackingNo + phone`；`type = SCAN` 需 `trackingNo`。

**分页参数**：`page, size, keyword, status, companyId, dateStart, dateEnd`

## 8. 用户端（学生）`/api/student`

### 8.1 账号注册 / 登录

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| POST | /register | 注册，body: `{username, password, confirmPassword, realName, phone}` | 免登录 |
| POST | /login | 登录，body: `{username, password}` | 免登录 |
| POST | /logout | 退出登录 | 免登录 |
| GET | /profile | 当前登录学生资料 | 学生登录 |
| PUT | /profile | 修改资料/密码，body: `{realName, phone, oldPassword?, newPassword?}` | 学生登录 |
| GET | /companies | 快递公司列表（下拉框） | 免登录 |

### 8.2 我的快递 / 我的收件 / 自助查询

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| GET | /query?keyword=手机号或单号 | 免登录查询，返回 `PACKAGE`（驿站入库快件）与 `SEND`（别人在线寄给我的寄件订单）两类记录，按 `type` 区分 | 免登录 |
| GET | /packages | 我的快递（按登录手机号匹配 `package` 收件记录） | 学生登录 |

> `/query` 返回字段：`type`、`id`、`trackingNo`、`orderNo`、`companyId`、`companyName`、`senderName`、
> `receiverName`、`receiverPhone`、`itemName`、`pickupCode`、`shelfNo`、`status`、`statusDesc`、`time`（入库/下单时间）、`pickupTime`。

### 8.3 在线寄件 `/api/student/send`（学生登录）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | / | 寄件下单，body: `{companyId, senderName, senderPhone, senderAddress, receiverName, receiverPhone, receiverAddress, itemName, weight?, expectTime?, remark?}` |
| GET | /page?page&size&status | 我的寄件分页（我下单的） |
| GET | /receive/page?page&size&status | 我的收件分页（别人在线寄给我：按登录学生手机号匹配 `receiver_phone`） |
| GET | /{id} | 寄件详情（下单人本人或收件人可查看） |
| GET | /logs/{id} | 物流轨迹（时间正序，下单人本人或收件人可查看） |
| POST | /cancel/{id} | 取消寄件（仅「待揽收」可取消，且仅下单人本人可操作） |

> `expectTime` 支持 `yyyy-MM-dd HH:mm` 或 `yyyy-MM-dd HH:mm:ss`。

### 8.4 存件（寄存）`/api/student/deposit`（学生登录）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | / | 提交存件申请，body: `{itemName, quantity?, depositDays?, expectTime?, remark?}` |
| GET | /page?page&size&status | 我的存件分页 |
| GET | /{id} | 存件详情 |
| POST | /cancel/{id} | 取消申请（仅「待到站」可取消） |

> 学生端未登录时统一返回 `{"code":401,"msg":"请先登录学生账号"}`；页面 `/student/center` 未登录会 302 跳转 `/student/login`。
