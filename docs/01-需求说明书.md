# 校园快递驿站管理系统 需求说明书

## 1. 项目背景与目标

高校快递驿站每日吞吐大量快件，传统人工纸质登记存在**登记混乱、取件通知不及时、快件状态难追踪、问题件处理无记录**等问题。

本系统旨在通过信息化手段，实现快件从「入库 → 通知 → 取件 → 归档」全流程的数字化管理，做到：

- 快件登记规范统一，一件一码、一件一库位；
- 取件凭证标准化，杜绝错取、冒领；
- 状态流转全程留痕，问题件可追溯；
- 数据统计可视化，辅助驿站运营决策。

## 2. 用户角色

| 角色 | 编码 | 权限说明 |
| --- | --- | --- |
| 超级管理员 | `SUPER_ADMIN` | 全部功能，含用户管理、日志、基础数据维护、数据导出 |
| 驿站员工 | `STAFF` | 快件入库、通知、取件、问题件登记、寄件揽收/物流更新、存件上架/取出；基础数据只读 |
| 学生用户 | `student_user` 表 | 用户端账号（免登录查询 + 登录后寄件/存件/我的快递） |

## 3. 功能需求

### 3.1 快件入库登记
- 录入：快递单号、快递公司、收件人姓名、收件人手机号、货架号（可自动分配）、备注。
- 校验：快递单号唯一，重复入库给出提示。
- 自动：生成 6 位不重复取件码；未选货架时自动分配第一个启用货架。
- 支持扫码枪连续扫码录入（回车提交）。

### 3.2 取件通知 / 取件确认
- 通知：向收件人发送取件通知（本系统以「模拟短信」实现，写入通知记录与日志），快件状态由「已入库待通知」变为「已通知待取件」。
- 取件：支持三种凭证方式——①取件码；②手机号后四位 + 快递单号；③扫码枪扫单号。取件成功后标记「已取件」并记录取件时间与方式。

### 3.3 快件查询
- 后台：按单号 / 手机号 / 姓名 / 取件码 / 状态 / 公司 / 日期范围组合查询。
- 学生端：免登录，输入手机号或快递单号即可查看快件状态、取件码、货架号。

### 3.4 问题件管理
- 问题类型：滞留、错件、破损、丢件、拒收、退回、其他。
- 流程：登记 → 处理中 → 已处理；处理时可同步将快件标记为「已退回」。

### 3.5 用户管理
- 账号新增 / 编辑 / 删除 / 重置密码，密码 BCrypt 加密。
- 角色区分，接口级权限校验（`@RequiresRole`）。

### 3.6 数据统计
- 概览：今日入库、今日取件、待取件、滞留、待处理问题件、累计快件。
- 图表：每日入库 / 取件趋势、快递公司占比、操作员业绩。
- 导出：快件数据导出为 Excel。

### 3.7 日志记录
- 登录日志：记录登录账号、IP、浏览器、系统、结果。
- 操作日志：AOP 自动记录模块、操作、参数、IP、耗时、结果。
- 快件日志：入库 / 通知 / 取件 / 转问题 / 退回等状态流转记录。

### 3.8 扩展功能
- 大屏看板：实时展示今日数据、趋势、占比，自动刷新。
- 滞留件定时任务：每日凌晨自动将超期未取快件标记为「滞留」。

### 3.9 用户端（学生）注册与登录
- 注册：账号（4-20 位）、姓名、手机号（11 位）、密码（6-20 位）+ 确认密码；账号唯一，密码 BCrypt 加密。
- 登录：账号 + 密码，登录状态保存在 Session（`loginStudent`），与学生端页面/接口一一对应；与后台管理员登录互不影响。
- 个人中心：查看 / 修改资料（姓名、手机号）、修改密码（需校验原密码）、退出登录。
- 登录后可查看「我的快递」：按登录手机号匹配驿站收件记录，显示状态、取件码、货架号。

### 3.10 在线寄件（用户端）与物流跟踪
- 下单：快递公司、寄件人姓名/手机号、取件地点、期望取件时间、收件人姓名/手机号/地址、物品名称、重量、备注。
- 单号：提交后生成寄件单号（S + 时间 + 随机），状态「待揽收」，可自助取消。
- 驿站处理：后台「寄件订单」中揽收（回填运单号）→ 更新为运输中 / 派送中 / 已签收，每步写入物流轨迹（含描述、网点、操作人、时间）。
- 物流查询：学生端「我的寄件」可查看下单学生、运单号、状态与物流轨迹时间轴（按时间正序）。
- 收件方查询：收件人登录后「我的收件」按收件手机号匹配别人在线寄给自己的寄件订单（含寄件人、运单号、状态与物流轨迹）；
  免登录的「快件查询」页输入手机号 / 快递单号 / 寄件单号，同时返回驿站入库快件与寄给自己的寄件订单。
- 归属校验：寄件详情与物流轨迹仅下单人本人或收件人（收件手机号一致）可查看；取消寄件仅下单人本人可操作。

### 3.11 存件（寄存）服务
- 申请：物品名称、数量、预计存放天数、预计送达时间、备注；提交后生成 6 位存件码与存件单号（D + 时间 + 随机），状态「待到站」。
- 驿站处理：后台「存件管理」接收上架（分配货架，可自动分配）→ 状态「在库」；学生取回时办理取出 → 状态「已取出」。
- 学生端：「我的存件」显示存件码、货架号与状态，未入站时可取消申请。

## 4. 业务规则

### 4.1 快件状态机

```
0 已入库待通知 ──通知──> 1 已通知待取件 ──取件──> 2 已取件（终态）
      │                        │
      └──────── 超 N 天未取 ────┴────> 3 滞留 ──登记问题──> 4 问题件 ──退回──> 5 已退回
```

### 4.2 关键规则
- 滞留天数：超过 3 天（可配置）未取件自动标记滞留。
- 取件码：6 位数字，全局不重复。
- 取件限制：仅「已通知待取件」「滞留」状态可办理取件；「已取件」不可重复取件。

### 4.3 寄件状态机（send_order.status）

```
0 待揽收 ──驿站揽收(回填运单号)──> 1 已揽收 ──> 2 运输中 ──> 3 派送中 ──> 4 已签收（终态）
   │
   └──学生取消 / 驿站取消──> 5 已取消
```

- 仅「待揽收」允许学生自助取消；驿站可在未签收前取消。
- 物流状态只能单向推进（运输中 → 派送中 → 已签收），回退会被拒绝。
- 每次状态变化写入 `send_order_log` 一条轨迹。

### 4.4 存件状态机（deposit_order.status）

```
0 待到站 ──驿站接收上架(分配货架)──> 1 在库 ──驿站办理取出──> 2 已取出（终态）
   │
   └──学生取消──> 3 已取消
```

## 5. 非功能需求
- 界面中文，后台 / 学生端均适配移动端。
- 密码加密存储，越权访问返回 403。
- 关键操作（入库、通知、取件、删除、用户管理等）写入操作日志。
