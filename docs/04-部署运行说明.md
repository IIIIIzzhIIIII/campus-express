# 校园快递驿站管理系统 部署运行说明

## 1. 环境要求

| 软件 | 版本 | 说明 |
| --- | --- | --- |
| JDK | 17 及以上（JDK 17/21/25/26 均可） | 编译与运行均需 JDK 17+ |
| Maven | 3.6+ | 也可用项目自带 `mvnw` Wrapper，无需安装 |
| MySQL | 8.0 | 已安装，服务名 `MySQL80` |
| IDE | IntelliJ IDEA | 开发用 |

> **编译与运行都必须使用 JDK 17 及以上版本**。请确认 `java -version` 输出为 17+，
> 若不是，请把 `JAVA_HOME` 指向 JDK 17+ 的安装目录，并把 `%JAVA_HOME%\bin` 加入 `PATH`。

## 2. 数据库初始化

1. 确认 MySQL 服务已启动（服务名 `MySQL80`）。
2. 执行脚本（默认账号 `root / 123456`）：

```bash
mysql -uroot -p123456 --default-character-set=utf8mb4 < sql/schema.sql
mysql -uroot -p123456 --default-character-set=utf8mb4 < sql/data.sql
```

也可用 Navicat 打开并依次执行这两个脚本。

### 已初始化过数据库的项目（升级用户端模块）

之前已经执行过 `schema.sql` + `data.sql` 的项目，只需再执行一次升级脚本即可（脚本幂等，可重复执行）：

```bash
mysql -uroot -p123456 --default-character-set=utf8mb4 < sql/upgrade-student-module.sql
```

该脚本会创建 `student_user`、`send_order`、`send_order_log`、`deposit_order` 四张表，并写入演示数据（学生账号 `stu001` / `stu002`，密码 `123456`）。

## 3. 修改配置

编辑 `src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    username: root
    password: "123456"
server:
  port: 8081
```

- 数据库账号密码按需修改。
- 本机 8080 已被其它程序占用，因此项目端口配置为 **8081**；如需换端口，修改 `server.port` 或用启动参数 `--server.port=xxxx`。

## 4. 启动方式

### 方式一：IDEA（推荐开发调试）

1. 用 IDEA 打开项目根目录。
2. `File → Project Structure → Project SDK` 选择 **JDK 17/21**。
3. 运行 `CampusExpressApplication`。

### 方式二：命令行（Maven Wrapper）

```bash
# 设置 JDK 17+（若系统默认 java 不是 17+）
set JAVA_HOME=C:\Program Files\Java\jdk-17

# 启动
mvnw spring-boot:run
```

> 不想安装 MySQL / 需要打包成 exe 时，请直接看《05-单机版与exe运行说明.md》，
> 单机版使用内置 H2 数据库与内置 JRE，双击即可运行。

### 方式三：打包成 jar 运行

```bash
mvnw clean package -DskipTests
java -jar target/campus-express.jar
```

## 7. 常见问题

| 问题 | 解决 |
| --- | --- |
| 启动报 `Port 8080 was already in use` | 修改 `server.port`（当前为 8081），或结束占用进程 |
| 访问 `http://localhost:8080/student` 报 Whitelabel Error Page (`status=404`) | 端口不对：项目端口是 8081，8080 被其它程序占用，请访问 `http://localhost:8081/student` |
| 页面 `/login`、`/student` 报 500 但 `/api/**` 正常 | 程序运行时 `target/classes` 被 clean/rebuild 删掉了，模板读不到；停止后在 IDEA 重新运行 |
| 用户端接口返回 `{"code":401,"msg":"请先登录学生账号"}` | 未登录或会话过期，请先访问 `/student/login` 登录；学生端与后台管理端是两套独立会话 |
| 报数据库连接失败 | 检查 MySQL 服务、账号密码、是否已执行建库脚本 |
| IDEA 编译报 `ExceptionInInitializerError` / `TypeTag :: UNKNOWN` / 大量「找不到符号」 | JDK 23+ 默认关闭了 classpath 注解处理器发现，Lombok 未生效。项目已在 pom 中用 `annotationProcessorPaths` 显式声明 Lombok（1.18.48）修复；若仍报错请 Invalidate Caches 后重新编译 |
| 依赖下载慢 | 已在 `~/.m2/settings.xml` 配置阿里云镜像 |
